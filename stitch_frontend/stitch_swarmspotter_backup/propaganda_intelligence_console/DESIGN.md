## Brand & Style

This design system establishes a high-precision, diagnostic instrument panel engineered for intelligence analysts, forensic researchers, and trust-and-safety operatives tracking hostile disinformation campaigns and coordinated bot swarms.

The aesthetic philosophy draws heavily from high-density data terminals, signal analyzers, and aerospace telemetry displays, executed with modern slate light-mode discipline. It rejects decorative softness in favor of deliberate, razor-sharp efficiency: hairline grids, structured metadata ledgers, tightly calibrated data density, and a monospaced numerical spine.

### Personality & Emotional Tenor
- **Analytical & Impartial:** UI chrome remains cold, neutral, and unobtrusive so anomalies and network clusters dominate the analyst's visual field.
- **Surgical Precision:** Every component feels measured to the half-pixel, communicating scientific rigor and evidential credibility.
- **Controlled Urgency:** Single-point vivid chromatic commitment directs focus to confirmed threats and automated vector triggers without inducing alarmist visual fatigue.

## Colors

The chromatic architecture is built on a high-clarity slate foundation calibrated for continuous, multi-hour investigative analysis under daylight or office illumination.

### Functional Roles
- **Primary (`#5A5CE3`):** The operational focus anchor. Reserved strictly for decisive interactive states: the active tab pill, selected network node clusters, focus rings, interactive anchor text, and confirmed actor links.
- **Primary Soft (`#EFF1FF`):** Tonal accent applied to selected row backgrounds, metadata filter badges, and tertiary control surfaces requiring tint differentiation without elevated contrast.
- **Secondary (`#2D3137`):** Command actions, utility navigation bars, structural splitters, and secondary buttons.
- **Tertiary (`#C2773B`):** Warm amber hue dedicated to network heuristics, categorical cluster tiles, node edge weighting, and non-critical data visualization dimensions.
- **Background (`#FAFBFD`):** Cool, anti-glare canvas base that isolates high-density data panels.
- **Surface (`#FFFFFF`):** High-clarity plane for data tables, inspection inspectors, and visual network graphs.
- **Surface 2 (`#F4F5F8`):** Recessed telemetry fields, data table headers, nested code blocks, and canvas toolbars.
- **Ink (`#1E2229`) & Ink 2 (`#62666D`):** Two-tier optical hierarchy; `Ink` enforces WCAG AAA contrast for primary findings, while `Ink 2` carries metric descriptors, timestamps, and column labels.
- **Line (`#DEE1E6`):** The structural armature. Hairline dividers, chart axis ticks, and table cell borders.
- **Inverse (`#22262D`):** Grounding layer for dark feature cards, floating telemetry overlays, and terminal toasts.
- **Status Accents:** Strict semantic assignment: Success (`#217B44`) for organic verified nodes, Warning (`#AB6C00`) for heuristic anomalies under review, Danger (`#BE423F`) for confirmed high-confidence bot networks and malicious amplification vectors.

## Typography

The typographic engine pairs **Inter** for human-readable navigational UI and structural headings with **JetBrains Mono** for all analytical intelligence: numerical scores, confidence metrics, coordinate vectors, account IDs, timestamps, and JSON entity payloads.

### Rules of Engagement
- **Tabular Figures Everywhere:** In tables and metric tiles, Inter must activate `font-feature-settings: "tnum" on, "cv05" on, "cv08" on` to prevent layout reflow during live stream parsing.
- **Monospaced Data Anchors:** All forensic properties (IP addresses, hash values, entity timestamps, cluster size counters, confidence percentages) are strictly rendered in `JetBrains Mono`.
- **Label Systematics:** Micro-labels and column metadata headers utilize `label-caps` in uppercase, maintaining fixed visual tracking across instrument panels.

## Layout & Spacing

Layout conforms to a compact 12-column analytical fluid grid system anchored by persistent multi-tier docking panels (Graph Explorer, Threat Registry, Entity Inspector).

### Spatial Metrics
- **Base Unit:** 4px geometric progression (`space-xs: 4px`, `space-sm: 6px`, `space-md: 12px`, `space-lg: 20px`, `space-xl: 32px`).
- **Dense Packing:** Vertical row heights are restricted to `28px` (compact) and `36px` (standard) to maximize data density per vertical viewport inch.
- **Split-Screen Telemetry:** Default desktop workspace allocates 60% viewport width to the force-directed graph or cluster visualizer, and 40% to the entity metadata inspection tray.

### Breakpoints & Adaptive Reflow
- **Desktop (>= 1440px):** Multi-pane workflow. 3-column synchronized views: Navigation sidebar (collapsed 48px or expanded 200px), Core Visualization (fluid), Detail Inspector (fixed 420px).
- **Laptop (1024px - 1439px):** Inspector transitions into an overlay drawer; data tables compress secondary columns using horizontal scroll locks.
- **Tablet & Compact (<= 1023px):** Workspace collapses to single-panel stacked mode; tabular views switch from fixed matrices to card-based summary tokens.

## Elevation & Depth

This design system rejects diffuse, floating shadows in favor of a **Tonal Layer + Hairline Structural Grid** approach. Depth is established through planar contrast and 1px continuous borders.

### Depth Hierarchy
- **Canvas Base (`#FAFBFD`):** Level 0. The outer perimeter and background canvas for graph coordinates.
- **Instrument Surface (`#FFFFFF`):** Level 1. Panels, cards, and data matrices bounded by a 1px solid `#DEE1E6` hairline border.
- **Inset Recesses (`#F4F5F8`):** Level -1. Input fields, nested JSON blocks, and telemetry metric beds set inside Level 1 surfaces with inner hairline framing.
- **Floating Diagnostic Overlays (Level 2):** Context menus, graph tooltips, and floating filter bars. Rendered on `#FFFFFF` with a crisp border (`#DEE1E6`) and an ambient micro-shadow: `0 2px 4px rgba(30, 34, 41, 0.04), 0 8px 16px rgba(30, 34, 41, 0.08)`.
- **System Command / Dark Layer (Level 3):** Urgent notices, terminal alerts, and critical batch prompts use `#22262D` (`Inverse`) with zero shadow, bordered by `rgba(255, 255, 255, 0.12)`.

## Shapes

The design system enforces **Soft (Tier 1)** geometry, using precise micro-radii that retain the severe, tool-like characteristics of analytical apparatus without visual harshness.

### Corner Radii Guidelines
- **Micro Radii (`rounded-sm: 2px`):** Checkbox indicators, inline tags, data chips, segmented control toggles, and table row selection markers.
- **Base Radii (`rounded: 4px`):** Standard interactive buttons, text fields, menu containers, and tooltips.
- **Panel Radii (`rounded-lg: 8px`):** Cards, modal dialogs, and workspace partition frames.
- **Pill Exceptions:** Restricted solely to quantitative counter badges (e.g., node counts) and circular avatar nodes within the graph visualizer.
